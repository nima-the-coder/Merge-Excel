 # Merge-Excel

ادغام‌کننده و پاک‌ساز فایل‌های اکسل
یک ابزار پایتونی با رابط گرافیکی برای ادغام چندین فایل اکسل، پاکسازی داده‌ها و خروجی گرفتن در قالب‌های اکسل و سی اس وی  

    ✨ ویژگی‌ها
-رابط کاربری گرافیکی (GUI) با استفاده از Tkinter

-انتخاب آسان پوشه با دیالوگ استاندارد

-ادغام خودکار تمام فایل‌های اکسل (.xlsx) در پوشه انتخاب شده

-پاکسازی داده‌ها: حذف سطرها و ستون‌های خالی، ستون‌های تکراری

-پیش‌نمایش فایل‌هایی که باید پردازش شوند

-خروجی گرفتن در هر دو قالب اکسل (.xlsx) و CSV

-مدیریت جامع خطاها و بازخورد کاربر

    🛠️ فناوری‌های استفاده شده
-پایتون ۳.۸+

-Pandas - عملیات دستکاری داده و اکسل

-Tkinter - رابط کاربری گرافیکی

-ماژول OS - عملیات سیستم فایل

    📋 پیش‌ نیازها
پایتون ۳.۸ یا بالاتر

نصب کتابخانه‌های مورد نیاز:

pip install pandas openpyxl

    🚀 نحوه استفاده
ابزار به طور خودکار:

تمام فایل‌های اکسل در پوشه را لیست می‌کند

آن‌ها را در یک DataFrame واحد ادغام می‌کند

داده‌ها را پاکسازی می‌کند (سطرها و ستون‌های خالی را حذف می‌کند)

نتایج را در پوشه output/ ذخیره می‌کند به عنوان:

clean_merged.xlsx

clean_merged.csv

    ⚠️ نکات
فقط فایل‌های .xlsx را پردازش می‌کند (نه .xls)

پوشه output/ را در صورت عدم وجود ایجاد می‌کند

انواع داده‌ها را در طول ادغام حفظ می‌کند

فایل CSV از رمزگذاری UTF-8-SIG برای سازگاری با فارسی/عربی استفاده می‌کند
